# Paguito Telcel — Resumen Ejecutivo

## ¿Qué es Paguito Telcel?

Es un **sistema de ventas por internet** diseñado especialmente para la venta de equipos Telcel. Permite que los clientes vean el catálogo de equipos desde su celular o computadora, hagan una reserva en línea y reciban la visita de un vendedor en su casa para concretar la venta. También permite a los administradores controlar el inventario, asignar vendedores y dar seguimiento a todas las reservas desde un solo lugar.

---

## Para el Cliente — Lo que el Público Ve y Hace

### 1. Catálogo de Productos
El cliente entra a la página y ve todos los equipos disponibles con fotos, precios, marcas y colores. Puede filtrar por marca, color, capacidad de almacenamiento (memoria) y rango de precio. También puede buscar por nombre del equipo. Todo se ve ordenado y actualizado en tiempo real.

### 2. Página de cada Producto
Si el cliente hace clic en un equipo, ve una página con:
- Varias fotos del equipo
- Precio actual y precio anterior (si tiene oferta)
- Colores disponibles
- Capacidades de almacenamiento disponibles
- Opción de pago de contado o crédito
- Un botón para agregarlo al carrito de reservas

Además, en la página principal se muestran los **equipos más vendidos** y las **ofertas especiales** para que el cliente los vea rápido.

### 3. Carrito de Reservas
El cliente puede agregar varios equipos a su carrito (como cuando compras en Amazon). Puede:
- Agregar o quitar productos
- Cambiar entre pago de contado o crédito para cada producto
- Ver el total de la reserva
- Pasar a confirmar la reserva cuando esté listo

### 4. Formulario de Reserva
Cuando el cliente decide reservar, llena un formulario con:
- Su nombre completo
- Teléfono
- CURP (para productos a crédito es obligatorio)
- Dirección donde quiere recibir la visita
- Fecha y horario preferido para la visita

El sistema valida que los horarios sean válidos (lunes a viernes de 9:30 a 4:30, sábados de 9:30 a 2:30). Los domingos no hay visitas.

### 5. Confirmación de Reserva
Una vez que confirma, el sistema:
- Le asigna automáticamente un número de folio para dar seguimiento
- Le asigna un vendedor disponible (de forma automática y justa)
- Le muestra una pantalla de éxito con los datos de su reserva

### 6. Consultar el Estado de mi Reserva
Desde la página "Mi Reserva", el cliente puede:
- Buscar su reserva por número de folio o CURP
- Ver en qué estado está su reserva (Nueva, Asignada, En Visita, Vendida, No Concretada)
- Ver qué productos pidió y en qué va cada uno
- Modificar la fecha u hora de su visita
- Cancelar productos individuales o toda la reserva

### 7. Chat de Atención (Asistente Inteligente)
En toda la página hay un chat disponible. No es una persona real, es un **asistente de inteligencia artificial** entrenado específicamente para responder dudas sobre:
- Información general de Telcel
- Cómo funciona el crédito
- Garantías
- Formas de pago
- Cualquier otra pregunta sobre los productos o el proceso de compra

El chat tiene límites para evitar abusos y se puede configurar desde el panel de administración para que responda exactamente lo que queremos.

### 8. Páginas Informativas
- **Preguntas Frecuentes (FAQ):** Respuestas a las dudas más comunes
- **Nosotros:** Información de la empresa
- **Dónde Pagar:** Información sobre cómo y dónde realizar los pagos

## Para el Vendedor — Lo que el Vendedor Ve y Hace

### 1. Tablero Personal
Cuando el vendedor inicia sesión, ve un resumen de:
- Cuántas reservas tiene asignadas en total
- Cuántas están activas (pendientes de visitar)
- Cuántas ha completado (vendidas)
- Cuántas visitas tiene pendientes para hoy

### 2. Mis Reservas Asignadas
El vendedor puede ver la lista de todas las reservas que le han asignado, con los datos del cliente, dirección y productos solicitados.

### 3. Mapa de Ubicaciones
El vendedor puede ver en un mapa las direcciones de los clientes que debe visitar, para planificar su ruta de visitas de forma eficiente.

### 4. Actualización de Estado
El vendedor puede ir actualizando el estado de cada reserva y cada producto:
- Pendiente → En Proceso → Vendido / No Concretado
- Si un producto se vende, el sistema descuenta automáticamente del inventario

## Para el Administrador — El Centro de Control

### 1. Tablero General (Dashboard)
El administrador ve una pantalla con:
- Cuántas reservas se hicieron hoy, esta semana y este mes
- Reservas activas, completadas y canceladas
- Cuántos vendedores están activos e inactivos
- Total de clientes registrados
- Gráficas de reservas por día
- Distribución de reservas por estado
- Ranking de vendedores por ventas realizadas

### 2. Gestión de Reservas
Pantalla completa para ver TODAS las reservas del sistema. Puede:
- Filtrar por estado, vendedor, fechas, tipo de pago
- Buscar por nombre de cliente
- Ver el detalle completo de cada reserva (productos, cliente, vendedor)
- Cambiar el estado de una reserva
- Asignar o reasignar un vendedor a una reserva
- Cancelar reservas
- Ver el historial de notificaciones enviadas para cada reserva

### 3. Gestión de Inventario (Productos)
Pantalla para administrar el catálogo de equipos:
- **Agregar** nuevos productos con fotos (hasta 3 por equipo), descripción, precio, colores, capacidades, etc.
- **Editar** productos existentes
- **Activar o desactivar** productos (sin borrarlos)
- **Eliminar** productos
- Ver si un producto tiene oferta (precio anterior)
- Controlar el stock y el stock mínimo
- Marcar si un producto está disponible a crédito

### 4. Gestión de Clientes
Directorio de todos los clientes que han hecho reservas. Puede:
- Buscar clientes por nombre, teléfono o correo
- Ver el historial de reservas de cada cliente
- Bloquear o desbloquear clientes

### 5. Gestión de Vendedores
Pantalla para administrar el equipo de ventas:
- Agregar nuevos vendedores
- Editar sus datos (nombre, teléfono, zona)
- Activar o desactivar vendedores
- Ver las reservas asignadas a cada vendedor

### 6. Gestión de Administradores
Similar a la de vendedores, pero para crear otros administradores que puedan acceder al panel de control.

### 7. Configuración de Asignación de Vendedores
El sistema puede asignar vendedores automáticamente de dos formas:
- **Automática (Round Robin):** Cuando llega una reserva nueva, el sistema asigna al vendedor que menos reservas haya recibido. Es justo y equitativo.
- **Manual:** Las reservas llegan sin vendedor asignado y un administrador las asigna manualmente.

El administrador puede cambiar entre estos dos modos cuando quiera.

### 8. Configuración de Notificaciones
El sistema puede enviar notificaciones automáticas por:
- **Correo electrónico:** Al cliente cuando se crea la reserva, al vendedor cuando se le asigna una, etc.
- **WhatsApp:** Mensajes automáticos al cliente y al vendedor

El administrador puede activar o desactivar los avisos de WhatsApp para clientes y para vendedores de forma independiente.

### 9. Resúmenes Automáticos por Correo
El sistema puede enviar automáticamente un resumen diario (o semanal) a los administradores con:
- Cuántas reservas nuevas se hicieron
- Cuántas ventas se concretaron
- Cuántas cancelaciones hubo
- Equipos que se quedaron sin stock
- Vendedores activos
- Total de reservas activas

Se puede configurar la hora y frecuencia del resumen.

### 10. Configuración del Chat (Asistente AI)
El administrador puede personalizar lo que responde el asistente virtual:
- Agregar o modificar secciones de información (horarios, políticas de crédito, garantías)
- Activar o desactivar secciones específicas
- Ver una vista previa de cómo responderá el chat antes de guardar los cambios
- Ver estadísticas de uso del chat (cuántas personas lo usan, cuántos mensajes, cuánto cuesta)

### 11. Registros del Sistema (Logs)
Pantalla para ver los registros de actividad del sistema:
- Errores y advertencias
- Filtrar por fecha y tipo
- Descargar archivos de registro
- Ver estadísticas de errores del día

### 12. Estado del Sistema
Pantalla con información técnica del servidor:
- Tiempo que lleva funcionando el servidor
- Memoria utilizada
- Estado de la base de datos
- Estado del sistema de caché

## Seguridad y Control de Acceso

El sistema tiene dos niveles de acceso bien definidos:
- **Vendedor:** Solo ve sus propias reservas asignadas y su tablero personal
- **Administrador:** Tiene acceso completo a todo el panel de control

Para acceder se necesita un correo y contraseña. Si alguien olvida su contraseña, puede solicitar un restablecimiento por correo electrónico.
